# US-02 — Simulasi Data Sensor BATARA

## Tujuan
Menguji simulasi data baterai 18650 sebelum
integrasi dengan perangkat fisik.

## Fitur
1. Simulasi tegangan baterai.
2. Simulasi arus discharge.
3. Simulasi suhu baterai.
4. Perhitungan kapasitas aktual.
5. Perhitungan State of Health (SoH).
6. Penggolongan Grade A, B, C, dan X.
7. Simulasi peringatan suhu dan arus.
8. Dashboard data simulasi.
9. Pengujian setiap skenario.
